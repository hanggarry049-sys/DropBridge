# DropBridge2 — 重写版

DropBridge 的重写版：**功能与 v1.0.x 一致，UI 大改**。旧版已冻结，暂停功能迭代。

## 开工前先读

| 文件 | 内容 |
| --- | --- |
| `../交接文档.md` | **主入口**（本地维护，不入库）。旧版资产清单、可搬走的代码、必重踩的坑、待拍板的行为口径表 |
| [`../src/DropBridge/`](../src/DropBridge/) | 旧版源码，**参考实现**，不是改造基础 |
| `../发布指南.md` | 发版 SOP（本地文件，不入库） |

## 目录约定（2026-10-19 定）

- 新版代码全部放在本目录内，**不改动 `../src/DropBridge/`**
- 新版是独立项目：自己的 `.csproj`、自己的程序集名（`DropBridge2`），避免与旧版产物混淆
- 旧版对应的构建脚本 `../build.bat` / `../publish.bat` 写死了旧 csproj 路径，新版另写一份
- `.gitignore` 在仓库根，已覆盖 `bin/` `obj/` `publish/`，新目录无需重复

## 数据目录

旧版用 `%LOCALAPPDATA%\DropBridge`。旧 `items.json` 里的 `X/Y` 是像素坐标，
与新版 UI 尺寸不兼容（见交接文档 §9.5）。

**当前约定：新版用独立数据目录 `%LOCALAPPDATA%\DropBridge2`，干净起步，不迁移旧数据。**
旧版继续用自己的目录，两者互不干扰。
