# DropBridge

把常用文件夹"挂"在屏幕边缘，随资源管理器出现、随时取用。

拖动一个文件夹到屏幕侧边的区域，它就变成一个悬浮图标停在那儿。之后你在任何一个文件夹里干活，只要切回资源管理器，这些图标就在手边——双击即打开。长时间没用的会缓慢下沉，重要的可以放到顶部常驻区，永不下沉。

## 快速开始

1. 从 [Releases](https://github.com/hanggarry049-sys/DropBridge/releases/latest) 下载 `DropBridge-v1.0.0-win-x64.zip` 并解压。**免安装**，不需要管理员权限。
2. 双击 `DropBridge.exe`。程序常驻系统托盘，不占任务栏。
3. 打开任意资源管理器窗口，把想常驻的文件夹拖到屏幕**侧边区域**。
4. 松手，图标就留在那儿了。

> **首次运行会被 Windows 拦一下。** 程序没有购买代码签名证书，SmartScreen 会提示「Windows 已保护你的电脑」。点 **更多信息 → 仍要运行** 即可。
> 想确认安全，可以先核对压缩包里的 `SHA256.txt`，程序不提权、只在你主动开启自启时才碰注册表。

## 用法

| 操作 | 效果 |
| --- | --- |
| 拖动文件夹到侧边区域 | 添加悬浮图标 |
| 双击悬浮图标 | 打开该文件夹 |
| 拖动图标到资源管理器窗口 | 同盘 = 移动（图标随之移除）；跨盘 = 复制（图标保留） |
| 拖动图标到顶部**常驻区** | 固定，永不下沉 |
| 拖动图标到底部**移除区** | 移除图标（不影响原文件夹） |
| 右键托盘图标 | 设置 / 打开数据目录 / 暂停下沉 / 整理排列 / 清空 / 退出 |

悬浮条**只在资源管理器位于前台且未最大化时出现**，切到别的程序立即隐藏。常驻区和移除区平时不可见，只有拖动图标时才会显现。

## 设置项

托盘图标右键 → 设置：

- 停靠侧（左 / 右）
- 下沉速度（像素 / 小时，0 = 不老化）
- 侧边区域宽度（占屏宽 5% ~ 40%）
- 顶部常驻区占比（0 ~ 50%）
- 图标尺寸（48 / 64 / 80）
- 开机自启
- 暂停下沉

设置与图标数据保存在 `%LOCALAPPDATA%\DropBridge`。

## 系统要求

- Windows 10（1607 及以上）/ Windows 11
- x64
- **无需预装 .NET** —— exe 已自包含运行时，解压即用

## 卸载

程序不装服务、不留后台进程。退出托盘图标后：

1. 删除 `DropBridge.exe`
2. 删除 `%LOCALAPPDATA%\DropBridge` 目录

如果开过「开机自启」，勾掉设置里的开关即可移除注册表项
（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `DropBridge`）。

## 已知限制

- 只在**主显示器**上显示，按主屏工作区定位。
- 资源管理器**最大化时隐藏** —— 需要悬浮条的通常是多窗口并排搬运的场景。
- 拖回资源管理器走的是同盘「移动」语义：文件夹被搬走后，原来的记录自然失效。
- 不监听文件夹在系统里的改名 / 移动，被改动过的记录需要移除后重新拖入。
